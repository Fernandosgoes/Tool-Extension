# Snov.io Support Tools

Розширення **Chrome (Manifest V3)** для агентів підтримки **Snov.io**, щоб надсилати структуровані дані на вебхуки **Make.com** — посилання для підтвердження та запити, пов’язані з **Fastspring**.

**Основна мова документації:** [English](../README.md). Це переклад **українською**.

---

## Призначення

- **Посилання підтвердження:** надсилає email одержувача, URL підтвердження та ім’я агента на вебхук підтвердження.
- **Fastspring:** надсилає внутрішні запити (повторна активація покупки, зміна email доступу до панелі оплати, дані рахунку, розблокування облікового запису) з додатковими полями за потреби. Payload завжи містить стабільний `reason_code` та текст `reason` **англійською** для Make.
- **Журнал:** історія в межах сесії браузера, повторне надсилання та очищення.
- **Налаштування:** реєстр агентів (локально); панель також відкривається іконкою шестерні в заголовку.
- **Мови інтерфейсу:** PT (BR), EN, ES, UA — перемикання циклом у заголовку.

## Вимоги

- **Google Chrome** (або інший Chromium з підтримкою MV3).
- Активні вебхуки Make (URL у `config.js`).

## Встановлення (режим розробника)

1. Відкрийте `chrome://extensions`.
2. Увімкніть **Режим розробника**.
3. **Завантажити розпаковане** та виберіть цю папку проєкту.

## Конфігурація

Відредагуйте **`config.js`**:

- `WEBHOOK_CONFIRMATION_URL`, `WEBHOOK_FASTSPRING_URL`
- `REQUEST_TIMEOUT_MS`, `MAX_LOG_ENTRIES`, `VERSION`
- `FASTSPRING_REASON_EN` — англійські підписи в полі `reason` (незалежно від мови інтерфейсу)

**Агенти:** додайте імена в **Налаштуваннях**; форми підтвердження та Fastspring використовують ці списки.

## Структура проєкту

| Шлях | Роль |
|------|------|
| `manifest.json` | Маніфест MV3, дозволи, popup, service worker |
| `popup.html` / `popup.css` / `popup.js` | Інтерфейс, форми, журнал, i18n під час роботи |
| `i18n.js` | Рядки інтерфейсу (PT / EN / ES / UA) |
| `background.js` | `POST` JSON на потрібний вебхук за `payload.type` |
| `config.js` | Вебхуки, таймаути, версія, `FASTSPRING_REASON_EN` |
| `PRD.md` | Внутрішня специфікація продукту (португальською) |
| `translations/` | Локалізовані копії англомовного README |
| `docs/sugestoes-e-melhorias/` | Спільний процес пропозицій (Google Docs / `.docx`) |

## Конфіденційність і межі застосування

Розширення надсилає **операційні дані** (email, посилання, нотатки, агент) на налаштовані URL. Призначене для **внутрішнього використання** з контрольованим поширенням. Не замінює вимоги відповідності вашої організації для сценаріїв Make.
